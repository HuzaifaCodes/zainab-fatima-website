## PLACEHOLDER — Replace with real audio files

These placeholder files prevent 404 errors during development.
The game handles audio failures gracefully, so the app works without sound files.

## Required Sound Files

Place these in `/public/sounds/`:

| File | Purpose | Suggested Source |
|------|---------|-----------------|
| `boot.mp3` | System boot sound | Sci-fi startup chime |
| `click.mp3` | Button click | Short digital beep |
| `success.mp3` | Password correct | Rising success tone |
| `failure.mp3` | Password wrong | Error buzz |
| `warning.mp3` | Timer warnings | Alarm beep |
| `tick.mp3` | Critical timer tick | Clock tick |
| `glitch.mp3` | Glitch effect | Static burst |
| `mission_unlock.mp3` | Mission starts | Impact + sweep |
| `dare.mp3` | Dare activated | Dramatic sting |
| `bonus.mp3` | Bonus time granted | Positive chime |
| `complete.mp3` | Quest complete | Epic finale |
| `ambient.mp3` | Background loop | Low drone/ambience |
| `scan.mp3` | Hint decrypting | Scanner beep |

## Free Sources
